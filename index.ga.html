Stór APT SvxLink DB9CR

⚠ D’aistrigh intleacht shaorga an leathanach seo go huathoibríoch agus d’fhéadfadh botúin a bheith ann. Is é an leagan Béarla an leagan údarásach. (English)

Pacáistí de svxlink-db9cr do Raspberry Pi OS agus Debian, in dhá chomhpháirt — roghnaigh ceann amháin:

  • main: tógálacha forbartha laethúla ón gcód foinseach is déanaí den fhorc seo, ní eisiúintí cobhsaí.
  • release: na heisiúintí oifigiúla SvxLink ón mbuntionscadal (upstream) (26.05 agus níos nuaí), tógtha ó chód foinseach neamhathraithe na heisiúna leis na socruithe tógála agus na gnéithe céanna leis na pacáistí laethúla. Coinnítear gach eisiúint; bogann apt upgrade chuig gach eisiúint nua ón mbuntionscadal.

Féach an stór cód foinseach le haghaidh sonraí.

Buntionscadal agus athruithe áitiúla

Is forc é seo a shioncronaítear go laethúil de sm0svx/svxlink, an tionscadal bunaidh SvxLink, le pacáistiú áitiúil agus gnéithe breise curtha leis (RTL-SDR, SipLogic, an pacáiste ar leith qtel, an stór APT seo, agus tuilleadh — féach CHANGELOG.MD don liosta iomlán). Chun a fheiceáil go díreach cad atá difriúil ón mbuntionscadal ag am ar bith, gan a bheith ag brath ar ghrianghraf anseo a d'fhéadfadh dul as dáta, déan comparáid beo ar GitHub: master an bhuntionscadail … master an fhorc seo.

Tús tapa

Rith ar an spriocchóras é (aimsítear an cód-ainm/an ailtireacht cheart go huathoibríoch):

# Iompórtáil an eochair shínithe phoiblí
curl -fsSL https://criede.github.io/svxlink-db9cr/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/svxlink-db9cr.gpg

# Cuir foinse an stóir leis. Roghnaigh an chomhpháirt:
#   main     tógálacha forbartha laethúla
#   release  eisiúintí oifigiúla ón mbuntionscadal (26.05 agus níos nuaí)
component=main
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/svxlink-db9cr.gpg arch=${arch}] https://criede.github.io/svxlink-db9cr ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/svxlink-db9cr.list

sudo apt update
sudo apt install svxlink

# Éigeantach roimh an gcéad tosú: cumraigh do stáisiún, do raidió agus an fhuaim.
# Níl sa chomhad pacáistithe ach teimpléad agus caithfear é a oiriúnú do do shocrú.
sudo editor /etc/svxlink/svxlink.conf

# Cumasaigh SvxLink ag am tosaithe agus tosaigh anois é.
sudo systemctl daemon-reload
sudo systemctl enable --now svxlink.service

# Seiceáil staid na seirbhíse agus lean a loga.
systemctl status svxlink.service
journalctl -u svxlink.service -f

# Cliant grafach EchoLink roghnach (teastaíonn timpeallacht deisce):
# sudo apt install qtel

Riachtanach: Ná tosaigh an tseirbhís sula gcuireann tú /etc/svxlink/svxlink.conf in eagar. Cumraigh ar a laghad aitheantas an stáisiúin, an loighic, an glacadóir/tarchuradóir agus socruithe fuaime/PTT do do chrua-earraí. Léann an tseirbhís an chonair seo trí /etc/default/svxlink.

Má thuairiscíonn apt update earráid 404 don fhoinse seo, níl cód-ainm do chórais á thógáil fós (féach an tábla thíos) — ina ionad sin, athraigh an cód-ainm in /etc/apt/sources.list.d/svxlink-db9cr.list go ceann de na cinn a dtacaítear leo. Ina dhiaidh sin, tógfaidh sudo apt upgrade rialta tógálacha laethúla nua (main) nó eisiúintí nua ón mbuntionscadal (release) go huathoibríoch.

Ná cumasaigh an dá chomhpháirt ag an am céanna mura dteastaíonn na tógálacha laethúla uait: bíonn an leagan is airde acu i gcónaí, mar sin shuiteálfadh apt iad in ionad na n-eisiúintí. Chun suiteáil atá ann cheana a athrú ó main go release, athraigh an chomhpháirt in /etc/apt/sources.list.d/svxlink-db9cr.list, rith sudo apt update, ansin suiteáil leagan na heisiúna go sainráite (is íosghrádú é), m.sh. sudo apt install svxlink=26.05.2-1~trixie. Tabhair faoi deara, i bpacáistí release (cód foinseach neamhathraithe ón mbuntionscadal), nach bhfuil na scripteanna TCL faoi /usr/share/svxlink cosanta mar chomhaid chumraíochta; coinnigh athruithe áitiúla in events.d/local/.

Athruithe cumraíochta a chur i bhfeidhm

Tar éis duit /etc/svxlink/svxlink.conf (nó aon chomhad modúil /etc/svxlink/svxlink.d/*.conf) a chur in eagar ar stáisiún atá ag rith, athlódáil é gan seisiún gníomhach a bhriseadh:

sudo systemctl reload svxlink.service

Seolann sé seo SIGHUP, agus nuair a fhaigheann SvxLink é athléann sé a chumraíocht. Úsáid sudo systemctl restart svxlink.service ina ionad sin mura cosúil go nglacann an athlódáil le hathrú (d'fhéadfadh atosú iomlán a bheith de dhíth ar roinnt socruithe, mar shampla cé na croíleacáin loighce nó gléasanna fuaime a lódáiltear).

Leagan níos sine a shuiteáil

Fanann leaganacha le déanaí ar fáil sa pool ar feadh tamaill tar éis iad a bheith ionadaithe (na cinn laethúla ar feadh seachtaine, na cinn seachtainiúla ar feadh míosa, na cinn mhíosúla ar feadh bliana — féach "Retention" (coinneáil) in UPSTREAM-SYNC.MD), mar sin is féidir droch-thógáil laethúil a rolladh siar de ghnáth. Ní bhaintear pacáistí eisiúna ón mbuntionscadal (comhpháirt release) choíche:

apt list -a svxlink   # nó qtel; liostaíonn sé gach leagan atá fós sa stór
sudo apt install svxlink=26.05.1+daily20260910.5.1.gabcdef012345-1~trixie
sudo apt-mark hold svxlink   # roghnach: cuireann sé cosc ar "apt upgrade" é a uasghrádú arís
# sudo apt-mark unhold svxlink   # níos déanaí, chun nuashonruithe uathoibríocha a atosú

Pacáistí

PacáisteÁbhar
svxlinkComhpháirteanna freastalaí (svxlink, remotetrx, svxreflector, croíleacáin loighce, scripteanna imeachta Tcl). Tógtha le: tacaíocht RTL-SDR thar USB go díreach (forc librtlsdr/rtl_tcp de chuid RTL-SDR Blog san áireamh do dhonglaí reatha V3/V4; tagann sé salach ar librtlsdr0/rtl-sdr an dáileacháin), an croíleacán loighce SipLogic a chuir an pobal ar fáil (PJSIP/pjproject san áireamh, nasctha go statach), GPIO trí libgpiod, agus tacaíocht do chodecanna fuaime agus breiseáin Speex/Opus/LADSPA. Suiteálann sé seirbhís systemd. Níl Qtel ná pacáistí fuaimeanna san áireamh.
qtelCliant grafach EchoLink (Qt6). Teastaíonn timpeallacht deisce agus an pacáiste svxlink den leagan céanna go díreach (roinneann sé a leabharlanna echolib/async).

Córais 32-giotán: Tógtar pacáistí armhf in aghaidh Raspbian (ARMv6+VFP), bunús Raspberry Pi OS 32-giotán, mar sin ritheann siad ar gach samhail Raspberry Pi lena n-áirítear an Pi 1, Zero agus Zero W, agus suiteálann siad ar Debian armhf freisin (tástáiltear an dá cheann). Ní thógtar i386 (ríomhairí pearsanta 32-giotán) ach do Debian 12: ní thacaíonn Debian 13 le córais i386 a shuiteáil a thuilleadh. Tá na gnéithe céanna sna pacáistí 32-giotán agus atá sna cinn 64-giotán.
