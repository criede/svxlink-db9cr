APT repozitár SvxLink DB9CR

⚠ Táto stránka bola preložená automaticky pomocou umelej inteligencie a môže obsahovať chyby. Záväzná je anglická verzia. (English)

Balíky svxlink-db9cr pre Raspberry Pi OS a Debian v dvoch komponentoch — vyber si jeden:

  • main: denné vývojové zostavenia z najnovšieho zdrojového kódu tohto forku, nie stabilné vydania.
  • release: oficiálne vydania SvxLink z materského projektu (26.05 a novšie), zostavené z nezmeneného zdrojového kódu vydania s rovnakými nastaveniami zostavenia a funkciami ako denné balíky. Každé vydanie sa zachováva; apt upgrade prechádza na každé nové vydanie materského projektu.

Podrobnosti nájdeš v zdrojovom repozitári.

Materský projekt a lokálne zmeny

Ide o denne synchronizovaný fork sm0svx/svxlink, pôvodného projektu SvxLink, s vlastným balíčkovaním a rozšíreniami funkcií navrchu (RTL-SDR, SipLogic, samostatný balík qtel, tento APT repozitár a ďalšie — úplný zoznam pozri v CHANGELOG.MD). Ak chceš kedykoľvek zistiť, čím presne sa fork líši od materského projektu, bez spoliehania sa na zastaraný snímok na tejto stránke, porovnaj to naživo na GitHube: master materského projektu … master tohto forku.

Rýchly štart

Spusti na cieľovom systéme (správne kódové meno a architektúra sa zistia automaticky):

# Import verejného podpisového kľúča
# (prijme sa len kľúč s týmto odtlačkom: E9CF E946 7D00 3148 AB93  EBAC 4ED4 4F53 51D8 1844)
tmp=$(mktemp -d)
curl -fsSL https://criede.github.io/svxlink-db9cr/pubkey.gpg | gpg --quiet --homedir "$tmp" --import
gpg --homedir "$tmp" --export E9CFE9467D003148AB93EBAC4ED44F5351D81844 | \
  sudo tee /usr/share/keyrings/svxlink-db9cr.gpg >/dev/null
rm -rf "$tmp"

# Pridanie zdroja repozitára. Zvoľ komponent:
#   main     denné vývojové zostavenia
#   release  oficiálne vydania materského projektu (26.05 a novšie)
component=release
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/svxlink-db9cr.gpg arch=${arch}] https://criede.github.io/svxlink-db9cr ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/svxlink-db9cr.list

sudo apt update
sudo apt install svxlink

# Povinné pred prvým spustením: nakonfiguruj stanicu, rádio a audio.
# Súbor z balíka je len šablóna a musí sa prispôsobiť tvojej zostave.
sudo editor /etc/svxlink/svxlink.conf

# Povolenie SvxLink pri štarte systému a jeho okamžité spustenie.
sudo systemctl daemon-reload
sudo systemctl enable --now svxlink.service

# Kontrola stavu služby a sledovanie jej protokolu.
systemctl status svxlink.service
journalctl -u svxlink.service -f

# Voliteľný grafický klient EchoLink (vyžaduje grafické prostredie):
# sudo apt install qtel

Povinné: Nespúšťaj službu pred úpravou súboru /etc/svxlink/svxlink.conf. Nastav aspoň identifikáciu stanice, logiku, prijímač/vysielač a nastavenia audia/PTT pre svoj hardvér. Služba číta túto cestu cez /etc/default/svxlink.

Ak apt update hlási pre tento zdroj chybu 404, pre kódové meno tvojho systému sa zatiaľ nezostavuje (pozri tabuľku nižšie) — zmeň kódové meno v /etc/apt/sources.list.d/svxlink-db9cr.list na niektoré z podporovaných. Potom bežný príkaz sudo apt upgrade automaticky stiahne nové denné zostavenia (main) alebo nové vydania materského projektu (release).

Nepovoľuj oba komponenty súčasne, pokiaľ nechceš denné zostavenia: tie majú vždy vyššiu verziu, takže by ich apt nainštaloval namiesto vydaní. Ak chceš prepnúť existujúcu inštaláciu z main na release, zmeň komponent v /etc/apt/sources.list.d/svxlink-db9cr.list, spusti sudo apt update a potom explicitne nainštaluj verziu vydania (ide o downgrade, t. j. prechod na nižšiu verziu), napr. sudo apt install svxlink=26.05.2-2~deb13. Upozorňujeme, že v balíkoch release (nezmenený zdrojový kód materského projektu) nie sú skripty TCL v /usr/share/svxlink chránené ako konfiguračné súbory; lokálne zmeny ukladaj do events.d/local/.

Uplatnenie zmien konfigurácie

Po úprave /etc/svxlink/svxlink.conf (alebo ľubovoľného súboru modulu /etc/svxlink/svxlink.d/*.conf) na bežiacej stanici konfiguráciu znovu načítaj bez prerušenia aktívnej relácie:

sudo systemctl reload svxlink.service

Tým sa odošle signál SIGHUP, na ktorý SvxLink znovu načíta svoju konfiguráciu. Ak sa zdá, že opätovné načítanie zmenu neprevzalo, použi namiesto toho sudo systemctl restart svxlink.service (niektoré nastavenia, napríklad ktoré logické jadrá alebo zvukové zariadenia sa načítavajú, môžu vyžadovať úplný reštart).

Inštalácia staršej verzie

Nedávne verzie zostávajú po nahradení novšou verziou ešte nejaký čas dostupné v poole (denné počas týždňa, týždenné počas mesiaca, mesačné počas roka — pozri časť „Retention“ (uchovávanie) v UPSTREAM-SYNC.MD), takže chybné denné zostavenie sa zvyčajne dá vrátiť späť. Balíky vydaní materského projektu (komponent release) sa nikdy neodstraňujú:

apt list -a svxlink   # alebo qtel; vypíše všetky verzie, ktoré sú v repozitári ešte k dispozícii
sudo apt install svxlink=26.05.1+daily20260910.5.1.gabcdef012345-1~deb13
sudo apt-mark hold svxlink   # voliteľné: zabráni tomu, aby ju "apt upgrade" opäť povýšil
# sudo apt-mark unhold svxlink   # neskôr, na obnovenie automatických aktualizácií

Balíky

BalíkObsah
svxlinkServerové komponenty (svxlink, remotetrx, svxreflector, logické jadrá, skripty udalostí Tcl). Zostavené s: podporou RTL-SDR priamo cez USB (pribalený fork librtlsdr/rtl_tcp od RTL-SDR Blog pre aktuálne prijímače V3/V4; koliduje s distribučnými balíkmi librtlsdr0/rtl-sdr), prispeným logickým jadrom SipLogic (pribalený PJSIP/pjproject, staticky linkovaný), GPIO cez libgpiod a podporou audio kodekov a pluginov Speex/Opus/LADSPA. Inštaluje službu systemd. Neobsahuje Qtel ani zvukové balíky. Obsahuje pravidlo udev, ktoré službe SvxLink a prihláseným používateľom desktopu umožňuje prístup k USB donglom RTL-SDR.
qtelGrafický klient EchoLink (Qt6). Vyžaduje grafické prostredie a balík svxlink v presne rovnakej verzii (zdieľa jeho knižnice echolib/async).
