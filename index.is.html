SvxLink DB9CR APT-pakkasafn

⚠ Þessi síða var þýdd sjálfvirkt með gervigreind og getur innihaldið villur. Enska útgáfan gildir. (English)

Pakkar úr svxlink-db9cr fyrir Raspberry Pi OS og Debian, í tveimur hlutum (components) — veldu einn:

  • main: daglegar þróunarsmíðar úr nýjasta frumkóða þessarar kvíslar (fork), ekki stöðugar útgáfur.
  • release: opinberar SvxLink-útgáfur upprunaverkefnisins (upstream) (26.05 og nýrri), smíðaðar úr óbreyttum frumkóða útgáfunnar með sömu smíðastillingum og eiginleikum og daglegu pakkarnir. Allar útgáfur eru varðveittar; apt upgrade færir sig yfir á hverja nýja útgáfu upprunaverkefnisins.

Sjá frumkóðasafnið fyrir nánari upplýsingar.

Upprunaverkefni og staðbundnar breytingar

Þetta er daglega samstillt kvísl af sm0svx/svxlink, upprunalega SvxLink-verkefninu, með staðbundinni pökkun og viðbótareiginleikum ofan á (RTL-SDR, SipLogic, sérstakur qtel-pakki, þetta APT-pakkasafn og fleira — sjá CHANGELOG.MD fyrir heildarlistann). Til að sjá nákvæmlega hvað er frábrugðið upprunaverkefninu á hverjum tíma, án þess að treysta á skyndimynd hér sem gæti úrelst, berðu saman beint á GitHub: master upprunaverkefnisins … master þessarar kvíslar.

Fljótleg byrjun

Keyrðu á markkerfinu (rétt kóðaheiti/högun er greind sjálfkrafa):

# Flyttu inn opinbera undirritunarlykilinn
curl -fsSL https://criede.github.io/svxlink-db9cr/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/svxlink-db9cr.gpg

# Bættu pakkasafninu við sem uppsprettu. Veldu hluta (component):
#   main     daglegar þróunarsmíðar
#   release  opinberar útgáfur upprunaverkefnisins (26.05 og nýrri)
component=main
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/svxlink-db9cr.gpg arch=${arch}] https://criede.github.io/svxlink-db9cr ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/svxlink-db9cr.list

sudo apt update
sudo apt install svxlink

# Skylda fyrir fyrstu ræsingu: stilltu stöðina þína, talstöðina og hljóðið.
# Skráin í pakkanum er aðeins sniðmát og verður að aðlaga hana að þínum búnaði.
sudo editor /etc/svxlink/svxlink.conf

# Virkjaðu SvxLink við ræsingu kerfisins og ræstu það núna.
sudo systemctl daemon-reload
sudo systemctl enable --now svxlink.service

# Athugaðu stöðu þjónustunnar og fylgstu með annálnum hennar.
systemctl status svxlink.service
journalctl -u svxlink.service -f

# Valfrjáls myndrænn EchoLink-biðlari (krefst skjáborðsumhverfis):
# sudo apt install qtel

Nauðsynlegt: Ekki ræsa þjónustuna fyrr en þú hefur breytt /etc/svxlink/svxlink.conf. Stilltu að minnsta kosti auðkenni stöðvarinnar, rökfræði (logic), viðtæki/sendi og hljóð-/PTT-stillingar fyrir vélbúnaðinn þinn. Þjónustan les þessa slóð í gegnum /etc/default/svxlink.

Ef apt update tilkynnir villu 404 fyrir þessa uppsprettu, er ekki enn smíðað fyrir kóðaheiti kerfisins þíns (sjá töfluna hér að neðan) — breyttu þá kóðaheitinu í /etc/apt/sources.list.d/svxlink-db9cr.list í eitt af þeim sem eru studd. Eftir það sækir venjulegt sudo apt upgrade sjálfkrafa nýjar daglegar smíðar (main) eða nýjar útgáfur upprunaverkefnisins (release).

Ekki virkja báða hlutana samtímis nema þú viljir daglegu smíðarnar: þær hafa alltaf hærra útgáfunúmer, svo apt myndi setja þær upp í stað útgáfnanna. Til að skipta núverandi uppsetningu úr main yfir í release skaltu breyta hlutanum í /etc/apt/sources.list.d/svxlink-db9cr.list, keyra sudo apt update og setja síðan útgáfuna upp sérstaklega (þetta er niðurfærsla í eldri útgáfu), t.d. sudo apt install svxlink=26.05.2-1~trixie. Athugaðu að í release-pökkum (óbreyttur frumkóði upprunaverkefnisins) eru TCL-skriftur undir /usr/share/svxlink ekki varðar sem stillingaskrár; geymdu staðbundnar breytingar í events.d/local/.

Stillingabreytingar teknar í notkun

Eftir að þú hefur breytt /etc/svxlink/svxlink.conf (eða hvaða /etc/svxlink/svxlink.d/*.conf einingaskrá sem er) á stöð sem er í gangi skaltu endurhlaða hana án þess að rjúfa virka lotu:

sudo systemctl reload svxlink.service

Þetta sendir SIGHUP, og við það les SvxLink stillingar sínar aftur. Notaðu frekar sudo systemctl restart svxlink.service ef endurhleðsla virðist ekki taka breytingu til greina (sumar stillingar, til dæmis hvaða rökfræðikjarnar eða hljóðtæki eru hlaðin, geta krafist fullrar endurræsingar).

Uppsetning eldri útgáfu

Nýlegar útgáfur eru áfram aðgengilegar í pool um tíma eftir að nýrri útgáfa hefur leyst þær af hólmi (daglegar í viku, vikulegar í mánuð, mánaðarlegar í ár — sjá "Retention" (varðveisla) í UPSTREAM-SYNC.MD), svo yfirleitt er hægt að snúa til baka frá gallaðri daglegri smíð. Útgáfupakkar upprunaverkefnisins (hlutinn release) eru aldrei fjarlægðir:

apt list -a svxlink   # eða qtel; sýnir allar útgáfur sem enn eru í safninu
sudo apt install svxlink=26.05.1+daily20260910.5.1.gabcdef012345-1~trixie
sudo apt-mark hold svxlink   # valfrjálst: kemur í veg fyrir að "apt upgrade" uppfæri hana aftur
# sudo apt-mark unhold svxlink   # síðar, til að hefja sjálfvirkar uppfærslur á ný

Pakkar

PakkiInniheldur
svxlinkÞjónshlutar (svxlink, remotetrx, svxreflector, rökfræðikjarnar, Tcl-atburðaskriftur). Smíðað með: stuðningi við RTL-SDR beint um USB (meðfylgjandi librtlsdr/rtl_tcp-kvísl frá RTL-SDR Blog fyrir núverandi V3/V4-kubba; stangast á við librtlsdr0/rtl-sdr dreifingarinnar), SipLogic-rökfræðikjarnanum frá samfélaginu (meðfylgjandi PJSIP/pjproject, statískt tengt), GPIO í gegnum libgpiod og stuðningi við Speex/Opus/LADSPA-hljóðkóðara og viðbætur. Setur upp systemd-þjónustu. Inniheldur hvorki Qtel né hljóðpakka.
qtelMyndrænn EchoLink-biðlari (Qt6). Krefst skjáborðsumhverfis og svxlink-pakkans í nákvæmlega sömu útgáfu (deilir echolib/async-söfnum hans).

32 bita kerfi: armhf-pakkar eru smíðaðir fyrir Raspbian (ARMv6+VFP), grunn 32 bita Raspberry Pi OS, svo þeir keyra á öllum gerðum Raspberry Pi, þar á meðal Pi 1, Zero og Zero W, og er einnig hægt að setja þá upp á Debian armhf (hvort tveggja er prófað). i386 (32 bita PC-tölvur) er aðeins smíðað fyrir Debian 12: Debian 13 styður ekki lengur uppsetningu i386-kerfa. 32 bita pakkarnir hafa sömu eiginleika og 64 bita pakkarnir.
