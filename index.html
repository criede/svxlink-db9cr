SvxLink DB9CR APT repository

Daily development packages of svxlink-db9cr for Raspberry Pi OS and Debian. These are daily builds from the latest source, not stable releases — see the source repository for details.

Quickstart

Run on the target system (detects the right codename/architecture automatically):

# Import the public signing key
curl -fsSL https://criede.github.io/svxlink-db9cr/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/svxlink-db9cr.gpg

# Add the repository source
codename=$(. /etc/os-release && echo "$VERSION_CODENAME")
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/svxlink-db9cr.gpg arch=${arch}] https://criede.github.io/svxlink-db9cr ${codename} main" | \
  sudo tee /etc/apt/sources.list.d/svxlink-db9cr.list

sudo apt update
sudo apt install svxlink

If apt update reports a 404 for this source, your system's codename isn't built yet (see the table below) — edit the codename in /etc/apt/sources.list.d/svxlink-db9cr.list to one of the supported ones instead. Afterwards, a regular sudo apt upgrade picks up new daily builds automatically.
