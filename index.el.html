Αποθετήριο APT του SvxLink DB9CR

⚠ Αυτή η σελίδα μεταφράστηκε αυτόματα με τεχνητή νοημοσύνη και ενδέχεται να περιέχει σφάλματα. Ισχύει η αγγλική έκδοση. (English)

Πακέτα του svxlink-db9cr για Raspberry Pi OS και Debian, σε δύο συνιστώσες (components) — επίλεξε μία:

  • main: καθημερινές εκδόσεις ανάπτυξης (daily builds) από τον πιο πρόσφατο πηγαίο κώδικα αυτού του fork, όχι σταθερές εκδόσεις.
  • release: οι επίσημες εκδόσεις του upstream SvxLink (26.05 και νεότερες), μεταγλωττισμένες από τον αμετάβλητο πηγαίο κώδικα των εκδόσεων upstream με τις ίδιες ρυθμίσεις μεταγλώττισης και τις ίδιες λειτουργίες με τα καθημερινά πακέτα. Κάθε έκδοση διατηρείται· η εντολή apt upgrade μεταβαίνει σε κάθε νέα έκδοση upstream.

Για λεπτομέρειες, δες το αποθετήριο πηγαίου κώδικα.

Upstream και τοπικές αλλαγές

Πρόκειται για ένα fork, συγχρονιζόμενο καθημερινά, του sm0svx/svxlink, του αρχικού έργου SvxLink, με τοπική πακετοποίηση και πρόσθετες λειτουργίες από πάνω (RTL-SDR, SipLogic, το ξεχωριστό πακέτο qtel, αυτό το αποθετήριο APT και άλλα — δες το CHANGELOG.MD για την πλήρη λίστα). Για να δεις ακριβώς τι διαφέρει από το upstream σε οποιαδήποτε χρονική στιγμή, χωρίς να βασίζεσαι σε ένα στιγμιότυπο εδώ που θα παλιώσει, κάνε τη σύγκριση ζωντανά στο GitHub: upstream master … master αυτού του fork.

Γρήγορη εκκίνηση

Εκτέλεσε στο σύστημα-στόχο (εντοπίζει αυτόματα τη σωστή κωδική ονομασία/αρχιτεκτονική):

# Εισαγωγή του δημόσιου κλειδιού υπογραφής
curl -fsSL https://criede.github.io/svxlink-db9cr/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/svxlink-db9cr.gpg

# Προσθήκη της πηγής του αποθετηρίου. Επίλεξε τη συνιστώσα (component):
#   main     καθημερινές εκδόσεις ανάπτυξης
#   release  επίσημες εκδόσεις upstream (26.05 και νεότερες)
component=release
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/svxlink-db9cr.gpg arch=${arch}] https://criede.github.io/svxlink-db9cr ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/svxlink-db9cr.list

sudo apt update
sudo apt install svxlink

# Υποχρεωτικό πριν από την πρώτη εκκίνηση: ρύθμισε τον σταθμό, τον πομποδέκτη και τον ήχο σου.
# Το αρχείο του πακέτου είναι μόνο ένα πρότυπο και πρέπει να προσαρμοστεί στη δική σου διάταξη.
sudo editor /etc/svxlink/svxlink.conf

# Ενεργοποίηση του SvxLink κατά την εκκίνηση του συστήματος και άμεση εκκίνησή του.
sudo systemctl daemon-reload
sudo systemctl enable --now svxlink.service

# Έλεγχος της κατάστασης της υπηρεσίας και παρακολούθηση του αρχείου καταγραφής της.
systemctl status svxlink.service
journalctl -u svxlink.service -f

# Προαιρετικός γραφικός πελάτης EchoLink (απαιτεί περιβάλλον επιφάνειας εργασίας):
# sudo apt install qtel

Απαιτείται: Μην εκκινήσεις την υπηρεσία πριν επεξεργαστείς το /etc/svxlink/svxlink.conf. Ρύθμισε τουλάχιστον την ταυτότητα του σταθμού, τη λογική (logic), τον δέκτη/πομπό και τις ρυθμίσεις ήχου/PTT για το υλικό σου. Η υπηρεσία διαβάζει αυτή τη διαδρομή μέσω του /etc/default/svxlink.

Αν η εντολή apt update αναφέρει σφάλμα 404 για αυτή την πηγή, δεν παράγονται ακόμη πακέτα για την κωδική ονομασία του συστήματός σου (δες τον πίνακα παρακάτω) — αντί γι' αυτό, άλλαξε την κωδική ονομασία στο /etc/apt/sources.list.d/svxlink-db9cr.list σε μία από τις υποστηριζόμενες. Στη συνέχεια, ένα συνηθισμένο sudo apt upgrade λαμβάνει αυτόματα τις νέες καθημερινές εκδόσεις (main) ή τις νέες εκδόσεις upstream (release).

Μην ενεργοποιείς και τις δύο συνιστώσες ταυτόχρονα, εκτός αν θέλεις τις καθημερινές εκδόσεις: αυτές έχουν πάντα τον υψηλότερο αριθμό έκδοσης, οπότε το apt θα τις εγκαθιστούσε στη θέση των εκδόσεων release. Για να αλλάξεις μια υπάρχουσα εγκατάσταση από main σε release, άλλαξε τη συνιστώσα στο /etc/apt/sources.list.d/svxlink-db9cr.list, εκτέλεσε sudo apt update και στη συνέχεια εγκατάστησε ρητά την έκδοση release (πρόκειται για υποβάθμιση έκδοσης, downgrade), π.χ. sudo apt install svxlink=26.05.2-1~trixie. Σημείωσε ότι στα πακέτα release (αμετάβλητος πηγαίος κώδικας upstream) τα σενάρια TCL κάτω από το /usr/share/svxlink δεν προστατεύονται ως αρχεία ρυθμίσεων· κράτα τις τοπικές αλλαγές στο events.d/local/.

Εφαρμογή αλλαγών στις ρυθμίσεις

Μετά την επεξεργασία του /etc/svxlink/svxlink.conf (ή οποιουδήποτε αρχείου ενότητας /etc/svxlink/svxlink.d/*.conf) σε σταθμό που λειτουργεί, φόρτωσε τις ρυθμίσεις ξανά χωρίς να διακοπεί μια ενεργή συνεδρία:

sudo systemctl reload svxlink.service

Αυτό στέλνει το σήμα SIGHUP, με το οποίο το SvxLink διαβάζει ξανά τις ρυθμίσεις του. Χρησιμοποίησε αντί γι' αυτό το sudo systemctl restart svxlink.service αν η επαναφόρτωση δεν φαίνεται να εφαρμόζει μια αλλαγή (ορισμένες ρυθμίσεις, όπως ποιοι πυρήνες λογικής ή ποιες συσκευές ήχου φορτώνονται, ενδέχεται να απαιτούν πλήρη επανεκκίνηση).

Εγκατάσταση παλαιότερης έκδοσης

Οι πρόσφατες εκδόσεις παραμένουν διαθέσιμες στο pool για κάποιο διάστημα αφού αντικατασταθούν (καθημερινά για μία εβδομάδα, εβδομαδιαία για έναν μήνα, μηνιαία για έναν χρόνο — δες την ενότητα «Retention» (διατήρηση) στο UPSTREAM-SYNC.MD), οπότε μια προβληματική καθημερινή έκδοση μπορεί συνήθως να αναιρεθεί (rollback). Τα πακέτα των εκδόσεων upstream (συνιστώσα release) δεν αφαιρούνται ποτέ:

apt list -a svxlink   # ή qtel· εμφανίζει όλες τις εκδόσεις που υπάρχουν ακόμη στο αποθετήριο
sudo apt install svxlink=26.05.1+daily20260910.5.1.gabcdef012345-1~trixie
sudo apt-mark hold svxlink   # προαιρετικά: εμποδίζει το "apt upgrade" να την αναβαθμίσει ξανά
# sudo apt-mark unhold svxlink   # αργότερα, για να συνεχιστούν οι αυτόματες ενημερώσεις

Υποστηριζόμενα συστήματα

Κωδική ονομασίαΑντιστοιχεί σεΑρχιτεκτονικές: main (καθημερινές)Αρχιτεκτονικές: release
bookwormDebian 12, Raspberry Pi OS Bookworm (64/32 bit)amd64 arm64 i386—
trixieDebian 13, Raspberry Pi OS Trixie (64/32 bit)amd64 arm64—

Συστήματα 32 bit: τα πακέτα armhf μεταγλωττίζονται για το Raspbian (ARMv6+VFP), τη βάση του Raspberry Pi OS 32 bit, οπότε λειτουργούν σε κάθε μοντέλο Raspberry Pi, συμπεριλαμβανομένων των Pi 1, Zero και Zero W, και εγκαθίστανται επίσης σε Debian armhf (και τα δύο έχουν δοκιμαστεί). Το i386 (PC 32 bit) μεταγλωττίζεται μόνο για το Debian 12: το Debian 13 δεν υποστηρίζει πλέον την εγκατάσταση συστημάτων i386. Τα πακέτα 32 bit περιέχουν τις ίδιες λειτουργίες με τα πακέτα 64 bit.
