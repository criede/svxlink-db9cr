APT repozitorij SvxLink DB9CR

⚠ Ova je stranica automatski prevedena pomoću umjetne inteligencije i može sadržavati pogreške. Mjerodavna je engleska verzija. (English)

Paketi svxlink-db9cr za Raspberry Pi OS i Debian, u dvije komponente — odaberi jednu:

  • main: dnevne razvojne izgradnje iz najnovijeg izvornog koda ovog forka, a ne stabilna izdanja.
  • release: službena izdanja SvxLinka iz izvornog projekta (26.05 i novija), izgrađena iz nepromijenjenog izvornog koda izdanja s istim postavkama izgradnje i značajkama kao dnevni paketi. Svako se izdanje zadržava; apt upgrade prelazi na svako novo izdanje izvornog projekta.

Pojedinosti potraži u repozitoriju izvornog koda.

Izvorni projekt i lokalne promjene

Ovo je svakodnevno sinkronizirani fork projekta sm0svx/svxlink, izvornog projekta SvxLink, s vlastitim pakiranjem i dodanim značajkama povrh njega (RTL-SDR, SipLogic, zaseban paket qtel, ovaj APT repozitorij i drugo — potpuni popis nalazi se u CHANGELOG.MD). Da bi u bilo kojem trenutku vidio točno po čemu se fork razlikuje od izvornog projekta, bez oslanjanja na zastarjelu snimku na ovom mjestu, usporedi uživo na GitHubu: master izvornog projekta … master ovog forka.

Brzi početak

Pokreni na ciljnom sustavu (ispravno kodno ime i arhitektura otkrivaju se automatski):

# Uvoz javnog ključa za potpisivanje
curl -fsSL https://criede.github.io/svxlink-db9cr/pubkey.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/svxlink-db9cr.gpg

# Dodavanje izvora repozitorija. Odaberi komponentu:
#   main     dnevne razvojne izgradnje
#   release  službena izdanja izvornog projekta (26.05 i novija)
component=release
codename=$(sed -n 's/^VERSION_CODENAME=//p' /etc/os-release | tr -d '"')
arch=$(dpkg --print-architecture)
echo "deb [signed-by=/usr/share/keyrings/svxlink-db9cr.gpg arch=${arch}] https://criede.github.io/svxlink-db9cr ${codename} ${component}" | \
  sudo tee /etc/apt/sources.list.d/svxlink-db9cr.list

sudo apt update
sudo apt install svxlink

# Obavezno prije prvog pokretanja: konfiguriraj stanicu, radio i zvuk.
# Datoteka iz paketa samo je predložak i mora se prilagoditi tvojoj postavi.
sudo editor /etc/svxlink/svxlink.conf

# Omogući SvxLink pri pokretanju sustava i pokreni ga odmah.
sudo systemctl daemon-reload
sudo systemctl enable --now svxlink.service

# Provjeri stanje usluge i prati njezin zapisnik.
systemctl status svxlink.service
journalctl -u svxlink.service -f

# Neobavezni grafički klijent EchoLink (potrebno je grafičko okruženje):
# sudo apt install qtel

Obavezno: Ne pokreći uslugu prije uređivanja datoteke /etc/svxlink/svxlink.conf. Konfiguriraj barem identifikaciju stanice, logiku, prijamnik/odašiljač te postavke zvuka/PTT-a za svoj hardver. Usluga čita ovu putanju putem /etc/default/svxlink.

Ako apt update za ovaj izvor prijavi pogrešku 404, za kodno ime tvojeg sustava paketi se još ne izgrađuju (pogledaj tablicu u nastavku) — umjesto toga promijeni kodno ime u /etc/apt/sources.list.d/svxlink-db9cr.list u neko od podržanih. Nakon toga uobičajeni sudo apt upgrade automatski preuzima nove dnevne izgradnje (main) ili nova izdanja izvornog projekta (release).

Ne omogućuj obje komponente istodobno, osim ako želiš dnevne izgradnje: one uvijek imaju višu verziju, pa bi ih apt instalirao umjesto izdanja. Da bi postojeću instalaciju prebacio s main na release, promijeni komponentu u /etc/apt/sources.list.d/svxlink-db9cr.list, pokreni sudo apt update, a zatim izričito instaliraj verziju izdanja (riječ je o vraćanju na nižu verziju), npr. sudo apt install svxlink=26.05.2-1~trixie. Imaj na umu da u paketima release (nepromijenjeni izvorni kod izvornog projekta) TCL skripte u /usr/share/svxlink nisu zaštićene kao konfiguracijske datoteke; lokalne promjene čuvaj u events.d/local/.

Primjena promjena konfiguracije

Nakon uređivanja /etc/svxlink/svxlink.conf (ili bilo koje datoteke modula /etc/svxlink/svxlink.d/*.conf) na pokrenutoj stanici ponovno učitaj konfiguraciju bez prekidanja aktivne sesije:

sudo systemctl reload svxlink.service

Time se šalje signal SIGHUP, na koji SvxLink ponovno čita svoju konfiguraciju. Ako se čini da ponovno učitavanje nije preuzelo promjenu, umjesto toga upotrijebi sudo systemctl restart svxlink.service (neke postavke, primjerice koje se logičke jezgre ili zvučni uređaji učitavaju, mogu zahtijevati potpuno ponovno pokretanje).

Instalacija starije verzije

Novije verzije ostaju dostupne u poolu još neko vrijeme nakon što ih zamijene novije (dnevne tjedan dana, tjedne mjesec dana, mjesečne godinu dana — pogledaj odjeljak „Retention” (zadržavanje) u UPSTREAM-SYNC.MD), pa se lošu dnevnu izgradnju obično može vratiti na prethodnu. Paketi izdanja izvornog projekta (komponenta release) nikada se ne uklanjaju:

apt list -a svxlink   # ili qtel; ispisuje sve verzije koje su još u repozitoriju
sudo apt install svxlink=26.05.1+daily20260910.5.1.gabcdef012345-1~trixie
sudo apt-mark hold svxlink   # neobavezno: sprječava da ga "apt upgrade" ponovno nadogradi
# sudo apt-mark unhold svxlink   # kasnije, za nastavak automatskih ažuriranja

Paketi

PaketSadržaj
svxlinkPoslužiteljske komponente (svxlink, remotetrx, svxreflector, logičke jezgre, Tcl skripte događaja). Izgrađeno s: podrškom za RTL-SDR izravno putem USB-a (priložen fork librtlsdr/rtl_tcp od RTL-SDR Bloga za aktualne prijamnike V3/V4; u sukobu s paketima librtlsdr0/rtl-sdr iz distribucije), doprinesenom logičkom jezgrom SipLogic (priložen PJSIP/pjproject, statički povezan), GPIO-om putem libgpiod te podrškom za audio kodeke i dodatke Speex/Opus/LADSPA. Instalira uslugu systemd. Ne sadrži Qtel ni zvučne pakete. Sadrži udev pravilo koje usluzi SvxLink i prijavljenim korisnicima radne površine daje pristup RTL-SDR USB donglovima.
qtelGrafički klijent EchoLink (Qt6). Zahtijeva grafičko okruženje i paket svxlink potpuno iste verzije (dijeli njegove biblioteke echolib/async).
