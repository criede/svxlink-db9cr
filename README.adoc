SvxLink
=======

[IMPORTANT]
.About this repository: criede/svxlink-db9cr
====
This repository is an automatically tracking fork of the original SvxLink
project, https://github.com/sm0svx/svxlink[sm0svx/svxlink]. A scheduled
workflow merges upstream's `master` into this fork's `master` every day, and
every published upstream release is picked up automatically as well.

Its *only purpose is building and publishing packages* (`.deb`) of SvxLink.
SvxLink itself is not developed here; local changes are limited to what the
packaging needs. Please report bugs and feature requests for SvxLink itself to
https://github.com/sm0svx/svxlink/issues[the upstream project].

*Packages:* `svxlink` (server components, systemd service) and `qtel`
(graphical EchoLink client), for Debian and Raspberry Pi OS:

* `arm64` -- Raspberry Pi OS 64-bit, Debian 12 (bookworm) and 13 (trixie)
* `armhf` -- Raspberry Pi OS 32-bit on every Raspberry Pi model (incl.
  Pi 1/Zero/Zero W), Debian armhf; bookworm and trixie
* `amd64` -- Intel/AMD PCs and servers, 64-bit; bookworm and trixie
* `i386` -- Intel/AMD PCs, 32-bit; bookworm only (Debian 13 no longer
  supports installing i386 systems)

*Two ways to get them:*

* *APT repository* (recommended, updates via `apt upgrade`):
  https://criede.github.io/svxlink-db9cr/ -- see the
  https://criede.github.io/svxlink-db9cr/#quickstart[quickstart]. Component
  `release`: the official upstream releases (26.05 and newer), built from the
  unmodified upstream source and kept permanently; component `main`: daily
  builds of this fork's `master`.
* *GitHub Releases*: https://github.com/criede/svxlink-db9cr/releases --
  `release-<version>` holds the packages of an upstream release,
  `daily-<version>` prereleases hold the daily builds; download the `.deb`
  files and install them with `sudo apt install ./svxlink_*.deb`.

Details on how the packages are built and published:

SvxLink is a project that develops software targeting the ham radio community.
It started out as an EchoLink application for Linux back in 2003 but has now
evolved to be something much more advanced.

== SvxLink Server ==
The SvxLink Server, often just called SvxLink, is a general purpose voice
services system, which when connected to a transceiver, can act as both an
advanced repeater system and can also operate on a simplex channel. One could
call it a radio operating system.

SvxLink is very extensible and modular. Voice services are implemented as
modules which are isolated from each other.  Modules can be implemented in
either C++ or TCL. Examples of modules are:

* *Help*               -- A help system
* *Parrot*             -- Play back everything that is received
* *EchoLink*           -- Connect to other EchoLink stations
* *DtmfRepeater*       -- Repeater received DTMF digits
* *TclVoiceMail*       -- Send voice mail to other local users
* *PropagationMonitor* -- Announce propagation warnings from dxmaps.com
* *SelCall*            -- Send selective calling sequences by entering DTMF codes
* *MetarInformation*   -- Play airport weather information
* *Frn*                -- Connect to Free Radio Network (FRN) servers
* *Trx*                -- Remote control tranceivers using DTMF

== Qtel ==
Qtel, the Qt EchoLink client, is a graphical application used to access the
EchoLink network.
